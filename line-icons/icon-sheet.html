Using an icon

Every shape carries its own literal stroke="#000000" rather than inheriting from the root, because Figma and Illustrator drop inherited paint on import and leave paths with no stroke.

That puts the attribute on the shape, so a recolouring rule has to reach the shape as well — a rule on the <svg> alone will not take:

.icon path { stroke: #A441BC; }  /* Menopause */
.icon path { stroke: #3F7EC1; }  /* Legacy */

Anything that rewrites paint at build time (SVGR, svg-sprite) handles this for you. Hover a tile to copy markup with a literal hex already baked in, ready to paste into a design tool.

Weight and size

Stroke sits on the <svg> element rather than per path, so one attribute changes a whole icon. 3.4 is measured against the 128 grid and scales proportionally — the size chips only change render size, never the spec.

The slider is a preview for comparing options. It always starts at 3.4 and is not remembered between visits.

Safe area

Artwork stays inside 24–104 on the 128 grid, measured on the path centerline — so with a 3.4 stroke the outermost ink lands at 22.3 and 105.7. Toggle Safe area in the bar to see the box.

Keep new icons inside it so everything sits on a common optical margin when set in a row.
