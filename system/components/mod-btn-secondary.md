# `.mod-btn-secondary`

The lower-emphasis variant of the module button pair. Documented together with
its primary, since they share a base rule and are designed to appear together:

**→ [Module buttons](mod-btn-primary.md)**

Key constraint worth repeating here: this variant is **dark-surface only**. It
is transparent with a white border and inverse text, so on a light background it
is effectively invisible.
