# Ask AI button (`.ai-btn`)

## Purpose

Opens the Ask AI assistant from the global navigation. It is the single entry
point to the assistant, and the only control in the nav that draws attention to
itself rather than waiting to be found.

## Use

- **Preferred** — one instance, in the top nav, on every persona.
- **Allowed** — the pulse, while the assistant has something to offer
  (`<body data-flow>`).
- **Avoid** — a second instance on the same screen. The pulse targets
  `.ai-btn` by selector and animating two at once reads as an error.
- **Prohibited** — pulsing indefinitely with no nudge to follow. The animation
  exists to lead somewhere.
- **Exception** — the narrow-phone layout drops the label and keeps the icon
  (see Variants), because the nav overflows below ~360px.
- **Rationale** — the assistant is new and unfamiliar. The ring earns attention
  once; a permanent pulse becomes noise and trains people to ignore it.

## Anatomy

| Part | Required | Notes |
|---|:-:|---|
| `.ai-btn` | yes | the pill; also carries `.icon-btn` |
| `.ai-btn__stars` | yes | gradient duo-star, 22px, inline SVG |
| `.ai-btn__label` | no | the word "Ask"; dropped on narrow phones |
| `::before` | — | the gradient ring, as an overlay so it animates independently of the icon |
| `::after` | — | the second ripple ring |

## Variants

No `--` modifiers. The two forms are driven by viewport, not by a class:
icon + label by default, icon only below the narrow-phone breakpoint.

## States

| State | Implemented | Behavior |
|---|:-:|---|
| Default | yes | gradient ring, transparent fill |
| Active | yes | `scale(0.95)` |
| Pulsing | yes | `ai-pulse`, 2.6s, infinite while `body[data-flow]` |
| One-shot pulse | yes | a single farewell pulse after the greeting closes |
| Quiet | yes | `.assistant-quiet` suppresses the animation |
| Typing | yes | `body.assistant-typing` drives `::after` |
| **Hover** | **no** | there is no distinct hover treatment |
| Focus-visible | yes | 2px `--color-primary` ring at pill radius, from the global rule |
| **Disabled** | **no** | the assistant is never unavailable in the prototype |

## Behavior

The pulse keyframes are built so the `100% → 0%` boundary lands at rest
(transparent, `scale(1)`). JS shows the nudge on that boundary, so a nudge can
never appear mid-ripple. Changing the keyframe timing without preserving that
resting boundary will make the nudge pop in over an expanding ring.

## Content

Label is **"Ask"** — one word, so the pill stays narrow enough to sit beside
search and the avatar. The accessible name is the fuller "Ask AI".

## Accessibility

- Semantic `<button>`.
- Accessible name `aria-label="Ask AI"`, which is deliberately longer than the
  visible "Ask" because the icon carries meaning the word alone does not.
- `@media (prefers-reduced-motion: reduce)` disables both the pulse and the
  `::after` ripple. This is required, not optional: the pulse is a large
  repeating scale-and-glow.
- Focus is a 2px `--color-primary` ring at pill radius, inherited from the
  global `:focus-visible` rule in `main.css`. Writing this contract is what
  surfaced its absence: the prototype had **no** focus styling at all — zero
  `:focus` rules across 64 rendered buttons — which was a system-wide blocker,
  not an `.ai-btn` problem. Fixed globally rather than here.
- Target size is 44px tall, meeting the minimum; width hugs content. **This is
  deliberate and confirmed (2026-09-18).** The Figma reference copy reachable
  today draws the control at 36×36 with a matching 22×22 glyph; 44px is an
  intentional uplift to the accessibility minimum, not drift. The Figma frames
  will be refreshed to match rather than the code being pulled back.

## Dependencies

- Tokens: `--radius-pill`, and `--color-accent` / `--color-primary` via
  `rgb(from …)` in the pulse keyframes.
- Composes `.icon-btn`.
- The duo-star gradient SVG is generated by `aiDuoStarsGradientSVG()` in
  `main.js`, which takes a unique gradient id per instance.

## Implementation

- Styles — `prototypes/navigation/main.css`, `.ai-btn*` and `@keyframes ai-pulse`.
- Markup — `prototypes/navigation/main.js`, in the mobile and desktop nav builders.
- Motion study — [system/motion/ai-pulse-spec.html](../motion/ai-pulse-spec.html).

## Rationale and decisions

- The label was shortened to "Ask" and the nav overflow fixed on narrow phones
  (commit `474c533`).
- The pulse ring colors were converted from baked `rgba()` to
  `rgb(from var(--color-accent) …)` so the ring re-skins with the site; before
  that it stayed purple on a blue site. See
  [decisions/DECISIONS.md](../../decisions/DECISIONS.md).
