05When it runs

At rest
The default. The pill sits in the nav with its gradient ring and label, no animation. Use this whenever the assistant has nothing to surface.
Trigger: none · the resting state.
Attention
The pulse runs to draw the eye toward the assistant when it has something to offer. Keep it time-boxed: it draws attention, then settles back to rest rather than looping indefinitely.
Trigger: the assistant becomes relevant (e.g. the user engages with related content).
Paused
While a message or greeting from the assistant is on screen, the pulse stops so the two don't compete for attention.
Trigger: a prompt, nudge, or panel is visible.
Farewell
After the message is dismissed, the pill emits a single pulse to re-anchor itself, then returns to rest.
Trigger: the message is closed or dismissed.
Reduced motion
When the user prefers reduced motion, the pulse never runs. Only the static ring and label remain.
Trigger: prefers-reduced-motion is set · overrides all states above.

06CSS

/* Attention pulse — layered on the .ai-btn nav pill.
   Runs only when <body> has a data-flow. */
body[data-flow]:not(.assistant-quiet):not(.assistant-onepulse) .ai-btn {
  animation: ai-pulse 2.6s ease-in-out infinite;
}
/* Single farewell pulse after the greeting closes */
body[data-flow="assistant"].assistant-onepulse .ai-btn {
  animation: ai-pulse 2.6s ease-in-out 1;
}

@keyframes ai-pulse {
  0%, 18% {
    box-shadow: 0 0 0 0 rgba(164,64,188,0), 0 0 0 0 rgba(15,87,168,0);
    transform: scale(1);
  }
  38% {
    box-shadow: 0 0 0 0 rgba(164,64,188,0.65), 0 0 0 0 rgba(15,87,168,0.45);
    transform: scale(1.08);
  }
  100% {
    box-shadow: 0 0 0 32px rgba(164,64,188,0), 0 0 0 20px rgba(15,87,168,0);
    transform: scale(1);
  }
}

@media (prefers-reduced-motion: reduce) {
  .ai-btn { animation: none; }
}
