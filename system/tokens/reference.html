Usage Guidelines

✓ Do
  • Use semantic tokens (color/text/primary) in components, not raw hex values
  • Use Body Large (18px) for all interactive elements
  • Maintain 44px minimum touch targets on mobile
  • Use core-Action/900 as the single primary interactive color
  • Reserve accent-Reaction + AI gradient for AI-specific features only
✕ Don't
  • Don't use raw hex values — reference tokens so changes propagate
  • Don't mix button variants in the same action group
  • Don't use Tertiary buttons as primary CTAs
  • Don't use color alone to convey state — pair with icon or label
♿

Accessibility

Minimum contrast: 4.5:1 for body text · 3:1 for large text and UI components.

Neutral/900 on whiteAAA 17.5:1
Action/900 on whiteAA 4.6:1
Error/900 on whiteAA 4.8:1
Success/900 on whiteAA 5.1:1
🤝

Contributing

  1. All new components must reference Figma Variables before shipping
  2. Add new colors to 🎨 Color Primitives first, then create a semantic alias in 🧩 Semantic Tokens
  3. New text styles go in the typography/ group in Figma Text Styles
  4. Update this reference doc when adding components or changing token values
  5. Link new Figma frames in the relevant section above
