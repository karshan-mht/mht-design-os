Shared icon set

Two sets in one place. The line icons are editorial: graphical, detailed, drawn on a 128 grid for display sizes. The UI glyphs at the end are solid shapes for interface chrome at 16–44px — a separate system, deliberately not merged. Both carry currentColor, so the same file renders purple on Menopause and blue on Legacy. Names describe what each icon shows rather than the condition it illustrates, so nothing is tied to one site. Switch themes in the bar to check either. Every tile is rendered from the SVG files under system/icons/ — this page is a specimen of them, not a second copy.

Using an icon

Every shape carries stroke="currentColor", so an icon inherits the colour of whatever it sits in and re-skins with the site theme.

That puts the attribute on the shape, so a recolouring rule has to reach the shape as well — a rule on the <svg> alone will not take:

.icon path { stroke: #A440BC; }  /* Menopause */
.icon path { stroke: #3F7EC1; }  /* Legacy */

Design tools are the exception: Figma and Illustrator drop inherited paint on import and leave paths with no stroke. COPY handles that — it bakes the current literal hex onto every shape before copying, so what lands in a design tool is already coloured.

Weight and size

Stroke sits on the <svg> element rather than per path, so one attribute changes a whole icon. 3.4 is measured against the 128 grid and scales proportionally — the size chips only change render size, never the spec.

The slider is a preview for comparing options. It always starts at 3.4 and is not remembered between visits.

Safe area

Artwork stays inside 24–104 on the 128 grid, measured on the path centerline — so with a 3.4 stroke the outermost ink lands at 22.3 and 105.7. Toggle Safe area in the bar to see the box.

Keep new icons inside it so everything sits on a common optical margin when set in a row.
